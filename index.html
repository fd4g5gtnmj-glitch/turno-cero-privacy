TURNO CERO TEST · ENTORNO DE DESARROLLO

Política de privacidad

Fecha de vigencia: 7 de octubre de 2026.

Esta política se aplica únicamente a Turno Cero TEST y a sus pruebas controladas con Meta y WhatsApp. No es la política final de un servicio productivo. No se utiliza para estancias reales, el piloto privado ni comunicaciones con clientes reales.

Finalidad y alcance

Turno Cero TEST permite comprobar el envío, recepción, correlación y estado de mensajes de prueba, y validar su integración técnica con un entorno de desarrollo privado. Solo deben participar administradores y participantes autorizados de las pruebas. No envíes datos de huéspedes, documentos, datos de pago ni información sensible.

Datos que pueden tratarse

El contenido de mensajes TEST; identificadores técnicos de aplicación, cuenta, número TEST, participante, conversación y mensaje; fechas y horas; estados de envío, entrega o error; y registros técnicos mínimos necesarios para diagnosticar fallos. Un identificador de WhatsApp puede identificar al participante y se trata como dato personal. Las credenciales y secretos no forman parte de la política pública ni deben aparecer en registros de diagnóstico.

Uso limitado

Los datos se usan exclusivamente para ejecutar y comprobar pruebas autorizadas, correlacionar respuestas y resolver incidencias. No se venden, no se utilizan para publicidad, elaboración de perfiles comerciales ni entrenamiento de modelos. Las pruebas deben usar contenido ficticio y recopilar solo lo necesario.

Servicios que intervienen

Meta Platforms y WhatsApp proporcionan WhatsApp Cloud API y la infraestructura de mensajería TEST. GitHub Pages aloja esta página pública. OpenAI Sites aloja los servicios privados de Turno Cero; su infraestructura de despliegue utiliza Cloudflare Workers y almacenamiento D1 cuando corresponda. Cada proveedor puede tratar datos técnicos conforme a sus propios términos y políticas. La publicación de esta página no habilita el transporte de WhatsApp ni expone los entornos privados. No se incorpora ningún intermediario comercial de WhatsApp.

Retención TEST

Los datos de las pruebas se conservarán únicamente mientras sean necesarios para comprobar el resultado o resolver una incidencia. Al cerrar cada prueba se revisarán para eliminar datos personales innecesarios. Las evidencias que deban mantenerse para validación se sanearán, sustituyendo identificadores personales y suprimiendo contenido sensible. Los proveedores pueden conservar sus propios registros según sus políticas; esta política no promete eliminarlos ni fija plazos que no se hayan verificado.

Seguridad

Los entornos de pruebas y sus datos se mantienen privados y con acceso restringido a operadores autorizados. Se usan conexiones HTTPS, minimización de registros y separación de credenciales y contenido público. No se publican tokens, claves, números personales ni mensajes de prueba en esta página. Ningún sistema puede garantizar una seguridad absoluta.

Derechos y eliminación de datos

Puedes solicitar información, acceso, rectificación, eliminación de tus datos TEST u oponerte a su tratamiento contactando con el responsable de Turno Cero TEST. Indica que tu solicitud se refiere a una prueba de WhatsApp y proporciona solo la referencia mínima necesaria para localizarla. No envíes contraseñas, tokens, documentos ni datos de pago. Se comprobará la identidad de forma proporcional y se eliminarán o sanearán los datos controlados por Turno Cero cuando proceda. Los datos gestionados directamente por Meta o WhatsApp también pueden requerir una solicitud a esos proveedores.
